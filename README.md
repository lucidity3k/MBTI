# MBTI Diagnostic Reference

Version: 0.2.0  
Purpose: 自由回答100問を終えた後の**最終照合専用**判定基準。診断中の質問生成には使わない。

## 0. 基本原則

このリポジトリはMBTIを絶対的分類として扱わない。目的は、100問の自由回答から観測された傾向を、複数候補の比較に使える一貫した基準へ接続すること。

禁止:
- 1つの回答や単語だけで型を決める
- ステレオタイプで人物像を補完する
- 「人が好き=F」「一人が好き=I」「計画好き=J」等の単純対応
- 現在の仕事・ストレス・防御反応を基底傾向として即採用
- このリポジトリに書かれた一般論を、本人が回答していない特徴として追加する
- 100回答よりこの文書を優先する

## 1. 最終診断時の参照順

1. `README.md` — 本規則、参照順、バージョン確認
2. `evidence.md` — 証拠強度、支持/反証、候補比較の方法
3. `axes.md` — E/I, S/N, T/F, J/P の観測基準
4. `functions.md` — 認知機能パターンを補助的に照合
5. `confounds.md` — 防御、擬態、役割適応、慢性ストレス、誤認要因

この順で読み、途中のファイルだけで型を確定しない。

## 2. 判定の主語

主語は常に「ユーザーの回答で観測された傾向」。  
文書の説明を人物へ逆輸入しない。

最終候補ごとに内部で以下を作る:

- SUPPORT: 候補を支持する回答群
- COUNTER: 候補と噛み合わない回答群
- UNCERTAIN: 未観測、曖昧、文脈依存
- MODE: 基底傾向か、現在の適応/防御モードか

第一候補は「典型像に最も近い型」ではなく、**回答全体を最少の無理で説明できる型**。
第二候補は、第一候補で説明しきれない残差を最もよく説明する型。
第三候補は近接誤認として意味がある場合のみ残す。

## 3. 証拠の扱い

優先度は概ね:

異文脈で再現する行動原理 > 理由付きの明確回答 > 条件付き回答 > 単発自己評価 > 単語・印象

長文だから強い証拠とは限らない。迷いもノイズではなく、「何を同時に守ろうとしているか」「どの条件で反転するか」の観測材料。

支持証拠だけでなく反証を必ず残す。候補が早く見えても、後半回答をその候補に合わせて解釈しない。

## 4. 軸と機能の関係

四軸は第一層の整理。認知機能は第二層の整合確認として使う。  
機能論が四軸と衝突した場合、どちらかを自動的に優先せず、回答の文脈と証拠強度を比較する。

機能名は最終説明で必要な場合のみ使い、一般論の羅列は禁止。

## 5. 基底傾向と現在モード

「仕事では」「家族には」「疲れている時」「以前は」「最近は」等は分離する。

基底傾向:
- 負荷が低い
- 自由裁量がある
- 長期的に繰り返す
- 他者から要求されなくても自然に出る

適応/防御モード:
- 役割要求で獲得
- 失敗回避や不信への対処
- 慢性ストレス下で強まる
- 特定対象・環境でのみ出る

両者がズレる場合、平均化して1つに潰さない。

## 6. 不確実性

100問終了は「完全確定」を意味しない。  
残る不確実性は追加質問で自動延長せず、最終結果の「断定できない点」「追加で詰める論点」へ出す。

確率値は計算根拠がない限り作らない。

## 7. 外部情報

このリポジトリ以外のWeb情報を最終判定基準として混ぜない。一般用語の確認が必要でも、候補順位を外部記事で変更しない。

## 8. 最終出力への接続

最終説明では、
- 回答から直接観測された点
- この基準と照合して推定した点
- まだ断定できない点
を混同しない。

MBTIは自己理解の補助線であり、人格・能力・適性・価値を断定するものではない。
